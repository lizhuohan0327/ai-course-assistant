# 数据结构常见错误与排查

## 1. 链表空指针
### 现象
程序崩溃或访问非法内存。

### 常见原因
- 未判断 head 是否为空；
- 删除节点后继续使用已经释放的指针；
- next 指针未初始化。

### 排查
- 每次解引用前确认指针非空；
- delete 后尽量将局部指针置为 nullptr；
- 画出链表指针变化图。

## 2. 数组越界
常见于顺序表、堆、循环队列。
重点检查：
- 下标是否从 0 开始；
- 容量和元素个数是否混淆；
- `i <= n` 是否应该写成 `i < n`。

## 3. 循环队列判满错误
若采用“牺牲一个单元”方式：
- 空：front == rear
- 满：(rear + 1) % capacity == front

不要同时把 front/rear 定义成多个不同语义。

## 4. 递归缺少终止条件
树遍历、DFS、归并排序、快速排序都依赖正确终止条件。
常见错误是区间没有缩小，导致无限递归。

## 5. DFS 忘记 visited
图中存在环时，可能无限递归。

## 6. Dijkstra 用于负权边
Dijkstra 的经典实现要求边权非负。
存在负权边时应考虑 Bellman-Ford 等算法。

## 7. 快速排序划分死循环
双指针移动时要保证每一轮指针确实向中间推进。

## 8. 二叉树遍历顺序记混
- 前序：根左右
- 中序：左根右
- 后序：左右根

## 9. 内存泄漏
动态创建的链表或树节点应在不再使用时释放。
课程实验中建议提供 destroy/free 函数。

## 10. 复杂度分析只看循环
函数调用、递归深度、数据结构操作复杂度也需要考虑。
