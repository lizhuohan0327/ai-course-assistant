# 第一章 绪论与算法复杂度

## 1. 数据结构基本概念
数据结构研究数据元素之间的逻辑关系、存储方式以及相应运算。

常见逻辑结构：
- 集合结构：元素之间除“属于同一集合”外没有其他关系。
- 线性结构：除首尾元素外，每个元素有且仅有一个直接前驱和一个直接后继。
- 树形结构：元素之间存在一对多关系。
- 图结构：元素之间存在多对多关系。

## 2. 存储结构
常见存储结构包括：
- 顺序存储
- 链式存储
- 索引存储
- 散列存储

逻辑结构与存储结构不是一一对应的。例如线性表既可以顺序存储，也可以链式存储。

## 3. 算法的基本特性
一个算法通常具有：
- 有穷性
- 确定性
- 可行性
- 输入
- 输出

## 4. 时间复杂度
时间复杂度用于描述算法运行时间随问题规模 n 增长的数量级。

常见数量级：
- O(1)
- O(log n)
- O(n)
- O(n log n)
- O(n^2)
- O(2^n)

分析原则：保留最高阶项，忽略常数系数。

示例：
```text
for i = 1..n:
    for j = 1..n:
        do constant work
```
时间复杂度为 O(n^2)。

## 5. 空间复杂度
空间复杂度表示算法执行过程中额外空间随 n 的增长关系。

递归算法需要考虑递归栈空间。

## 6. 易错点
- 把“实际运行秒数”与“时间复杂度”混淆。
- 忽略循环嵌套层数。
- 认为顺序表一定优于链表。
- 分析递归算法时遗漏递归调用栈。
