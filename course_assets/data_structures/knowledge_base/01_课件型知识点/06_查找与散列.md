# 第六章 查找与散列

## 1. 顺序查找
适用于无序表。
时间复杂度 O(n)。

## 2. 折半查找
前提：数据必须有序，并且适合随机访问。
时间复杂度 O(log n)。

## 3. 二叉搜索树查找
平均性能取决于树高。
若树高度为 h，查找复杂度为 O(h)。

## 4. 散列表
通过散列函数将关键字映射到表中位置。

常见冲突处理：
- 开放定址法
- 链地址法

### 开放定址法
发生冲突后继续寻找下一个可用位置。

### 链地址法
每个桶维护一个链表或其他容器。

## 5. 装填因子
`α = 表中元素个数 / 散列表容量`

装填因子越高，一般冲突概率越高。

## 6. 典型考点
- 构造散列表。
- 计算平均查找长度 ASL。
- 分析不同冲突处理方法。
- 判断折半查找的前提。
