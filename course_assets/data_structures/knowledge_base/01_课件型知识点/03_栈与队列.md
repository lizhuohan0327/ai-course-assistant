# 第三章 栈与队列

## 1. 栈
栈是只允许在一端进行插入和删除的线性表，遵循 LIFO（后进先出）。

常见操作：
- push
- pop
- top
- empty

应用：
- 括号匹配
- 表达式求值
- 递归
- 深度优先搜索
- 撤销操作

## 2. 顺序栈
使用数组实现。
栈顶指针 top 常见约定：
- top = -1 表示空栈；
- 入栈先 ++top 再赋值，或先赋值再 ++top，需要统一。

## 3. 链栈
通常在链表头部完成入栈和出栈，操作均可达到 O(1)。

## 4. 队列
队列遵循 FIFO（先进先出）。
基本操作：
- enqueue
- dequeue
- front

## 5. 循环队列
数组实现队列时，为避免“假溢出”，通常使用循环队列。

常用判空：
`front == rear`

为区分队满与队空，常用牺牲一个存储单元：
`(rear + 1) % capacity == front`

队列元素个数：
`(rear - front + capacity) % capacity`

## 6. 双端队列
允许两端插入和删除，常用于滑动窗口问题。

## 7. 高频错误
- 循环队列的 front/rear 语义不统一。
- 忘记取模。
- pop 前不判空。
- 把 BFS 和 DFS 所用的数据结构混淆。
