# 第二章 线性表

## 1. 定义
线性表是具有相同数据类型的 n 个数据元素的有限序列。

## 2. 顺序表
顺序表使用连续存储空间保存元素。

### 优点
- 随机访问效率高，按下标访问为 O(1)。
- 存储密度高。

### 缺点
- 插入、删除通常需要移动元素，时间复杂度 O(n)。
- 容量固定时可能发生溢出。

## 3. 单链表
链表节点由数据域和指针域组成。

### 特点
- 不要求物理地址连续。
- 已知插入位置前驱节点时，插入操作可在 O(1) 完成。
- 按序号查找需要 O(n)。

## 4. 双向链表
节点通常包含 prev、data、next 三部分。
适合需要频繁前后移动的场景。

## 5. 循环链表
尾节点指针指向头节点，可从任意节点开始遍历整个表。

## 6. 典型操作复杂度

| 操作 | 顺序表 | 单链表 |
|---|---:|---:|
| 按下标访问 | O(1) | O(n) |
| 查找指定值 | O(n) | O(n) |
| 表尾插入 | O(1)~O(n) | O(n)，有尾指针时 O(1) |
| 已知位置插入 | O(n) | 找到前驱后 O(1) |
| 删除 | O(n) | 找到前驱后 O(1) |

## 7. 典型考点
- 头插法与尾插法建立链表。
- 删除单链表中值为 x 的节点。
- 逆置单链表。
- 合并两个有序链表。
