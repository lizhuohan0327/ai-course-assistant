# 第四章 树与二叉树

## 1. 基本术语
- 根节点
- 双亲节点
- 孩子节点
- 兄弟节点
- 叶子节点
- 节点的度
- 树的高度/深度

## 2. 二叉树
二叉树每个节点最多有两个孩子，分别称左孩子和右孩子。

### 特殊二叉树
- 满二叉树
- 完全二叉树
- 二叉搜索树
- 平衡二叉树

## 3. 二叉树遍历
### 前序
根 -> 左 -> 右

### 中序
左 -> 根 -> 右

### 后序
左 -> 右 -> 根

### 层序
从上到下、从左到右，通常使用队列。

## 4. 二叉搜索树 BST
对任意节点：
- 左子树关键字小于该节点；
- 右子树关键字大于该节点（具体等号规则依实现而定）。

平均查找复杂度接近 O(log n)，最坏退化为链表时为 O(n)。

## 5. 哈夫曼树
带权路径长度 WPL 最小的二叉树。
哈夫曼编码是前缀编码，任意字符编码都不是另一个字符编码的前缀。

## 6. 重点题型
- 根据遍历序列还原二叉树。
- 计算树高、节点数、叶子节点数。
- 判断是否为二叉搜索树。
- 构造哈夫曼树与编码。
