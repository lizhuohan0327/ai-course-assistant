# 第七章 排序

## 1. 插入排序
将当前元素插入前面已经有序的序列。
平均 O(n^2)，稳定。

## 2. 希尔排序
对插入排序进行分组优化。
通常不稳定。

## 3. 冒泡排序
相邻元素不断比较交换。
平均 O(n^2)，稳定。

## 4. 快速排序
选择枢轴进行划分。
平均 O(n log n)，最坏 O(n^2)，通常不稳定。

## 5. 选择排序
每一趟从未排序区间选择最小元素。
O(n^2)，通常不稳定。

## 6. 堆排序
利用大根堆或小根堆。
O(n log n)，不稳定。

## 7. 归并排序
分治思想。
O(n log n)，稳定，需要额外 O(n) 空间。

## 8. 各排序算法对比

| 算法 | 平均 | 最坏 | 额外空间 | 稳定性 |
|---|---:|---:|---:|---|
| 插入排序 | O(n^2) | O(n^2) | O(1) | 稳定 |
| 冒泡排序 | O(n^2) | O(n^2) | O(1) | 稳定 |
| 快速排序 | O(n log n) | O(n^2) | O(log n)~O(n) | 不稳定 |
| 选择排序 | O(n^2) | O(n^2) | O(1) | 不稳定 |
| 堆排序 | O(n log n) | O(n log n) | O(1) | 不稳定 |
| 归并排序 | O(n log n) | O(n log n) | O(n) | 稳定 |
