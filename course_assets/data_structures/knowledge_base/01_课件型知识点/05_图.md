# 第五章 图

## 1. 基本概念
图 G=(V,E)，其中 V 是顶点集合，E 是边集合。

图可分为：
- 有向图 / 无向图
- 带权图 / 无权图
- 连通图 / 非连通图

## 2. 存储结构
### 邻接矩阵
适合稠密图。
空间复杂度 O(V^2)。

### 邻接表
适合稀疏图。
空间复杂度约 O(V+E)。

## 3. 图遍历
### DFS 深度优先搜索
通常借助递归或栈。

### BFS 广度优先搜索
使用队列。

## 4. 最小生成树
### Prim
从一个顶点开始不断加入与当前生成树距离最近的顶点。
更适合稠密图。

### Kruskal
按边权从小到大选边，使用并查集判断是否成环。
更适合稀疏图。

## 5. 最短路径
### Dijkstra
适用于边权非负的单源最短路径问题。

### Floyd
用于求所有顶点对之间的最短路径，时间复杂度 O(V^3)。

## 6. 拓扑排序
适用于有向无环图 DAG。
若无法输出全部顶点，则图中存在环。

## 7. 典型错误
- Dijkstra 不能直接处理负权边。
- BFS 的“最短路”结论只适用于无权图或等权图。
- 无向图的边在邻接表中通常存两次。
