# 数据结构课程自测题

## 一、判断与简答
1. 顺序表的插入操作时间复杂度一定是 O(n) 吗？说明原因。
2. 单链表按下标访问第 k 个元素的复杂度是多少？
3. 栈和队列的核心操作次序分别是什么？
4. 为什么循环队列可以避免“假溢出”？
5. 二叉搜索树最坏情况下为什么会退化成 O(n) 查找？
6. DFS 和 BFS 分别常用什么辅助结构？
7. Dijkstra 为什么不能直接处理负权边？
8. 折半查找为什么要求数据有序？
9. 哈希冲突有哪些常见处理方法？
10. 哪些常见排序算法是稳定的？

## 二、算法设计题
1. 逆置单链表。
2. 判断一个字符串括号是否匹配。
3. 求二叉树叶子节点个数。
4. 对无向图进行 BFS。
5. 实现折半查找。
6. 实现快速排序。
7. 使用链地址法实现简单哈希表。

## 三、综合比较题
比较以下数据结构的适用场景：
- 顺序表 vs 链表
- 栈 vs 队列
- 邻接矩阵 vs 邻接表
- BST vs 哈希表
- 快速排序 vs 归并排序
