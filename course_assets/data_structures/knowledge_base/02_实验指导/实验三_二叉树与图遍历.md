# 实验三 二叉树与图遍历

## 一、实验目标
1. 掌握二叉树节点定义和递归遍历。
2. 掌握 DFS 与 BFS。
3. 理解树遍历与图遍历中“访问标记”的差异。

## 二、任务 A：二叉树
要求实现：
- 前序遍历
- 中序遍历
- 后序遍历
- 层序遍历
- 统计节点数
- 统计叶子节点数
- 计算树高

## 三、任务 B：图遍历
使用邻接表实现无向图，并完成：
- DFS
- BFS

## 四、测试要求
图至少包含：
- 连通图
- 非连通图
- 存在环的图

## 五、验收要点
- 图遍历必须使用 visited 数组或集合；
- 非连通图要从所有未访问节点继续遍历；
- BFS 使用队列；
- DFS 可使用递归或显式栈。
