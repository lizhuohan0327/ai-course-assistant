# 实验一 线性表基本操作

## 一、实验目标
1. 掌握顺序表和单链表的基本实现。
2. 理解插入、删除、查找操作。
3. 比较顺序存储与链式存储的特点。

## 二、实验任务
实现一个学生成绩表，至少支持：
- 添加学生
- 按学号删除
- 按学号查找
- 输出全部学生
- 统计平均成绩

建议分别使用顺序表和单链表完成一次。

## 三、数据结构建议
```cpp
struct Student {
    int id;
    string name;
    double score;
};
```

## 四、测试数据
至少测试：
1. 空表插入；
2. 表头插入；
3. 表尾插入；
4. 删除不存在元素；
5. 删除首节点；
6. 删除尾节点；
7. 连续删除多个节点。

## 五、验收标准
- 功能正确；
- 无越界访问；
- 无明显内存泄漏；
- 能解释顺序表和链表复杂度差异；
- 能说明为什么链表不能 O(1) 按下标随机访问。

## 六、思考题
1. 若需要频繁按下标读取数据，优先使用哪种结构？
2. 若需要频繁在中间插入删除，链表是否一定更快？
3. 为什么“找到插入位置”本身可能仍需要 O(n)？
