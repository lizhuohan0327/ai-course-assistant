# 实验二 栈与队列及表达式处理

## 一、实验目标
1. 掌握栈和队列的基本操作。
2. 学会利用栈解决括号匹配问题。
3. 理解中缀表达式转后缀表达式的基本思想。

## 二、任务 A：括号匹配
输入包含 ()[]{} 的字符串，判断括号是否匹配。

### 要求
- 左括号入栈；
- 遇到右括号时检查栈顶；
- 最终栈应为空。

## 三、任务 B：循环队列
实现固定容量循环队列，支持：
- enqueue
- dequeue
- front
- empty
- full

## 四、边界测试
- 空栈 pop；
- 空队列 dequeue；
- 队满后继续 enqueue；
- 只有一对括号；
- 多层嵌套；
- 错误嵌套，如 `([)]`。

## 五、拓展任务
实现中缀表达式转后缀表达式，并计算简单整数表达式。
