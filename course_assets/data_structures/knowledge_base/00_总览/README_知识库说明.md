# 数据结构课程专属知识库

## 1. 知识库定位
本知识库面向“数据结构”课程学习、实验、复习与智能问答场景，可直接用于 Open WebUI、RAG、向量数据库或普通课程资料管理。

## 2. 资料类型
本知识库至少包含以下 4 类资料：
1. **课件型知识点文档**：按课程章节梳理概念、性质、复杂度和典型算法。
2. **实验指导书**：给出实验目标、任务、输入输出要求、测试点和验收标准。
3. **示例代码**：使用 C++ 展示典型数据结构与算法实现。
4. **常见错误说明**：汇总学习与编程中的高频错误、原因及排查方式。

## 3. 章节分类
- 绪论与复杂度
- 线性表
- 栈与队列
- 串、数组与广义表
- 树与二叉树
- 图
- 查找与散列
- 排序
- 综合实验
- 常见错误与自测

## 4. 推荐导入方式
若用于 RAG，建议按“一个文件一个主题”导入，切块时优先按 Markdown 标题分块。
建议 chunk size 500~1000 中文字符，overlap 100~200 字符。

## 5. 命名规范
文件名采用“章节_主题”形式，便于检索和后续维护。
