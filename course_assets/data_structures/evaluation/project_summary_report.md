# 数据结构 AI 助教项目总结报告

## 一、项目概述

本项目基于 Open WebUI 构建“数据结构 AI 助教”，面向数据结构课程学习场景。系统通过课程知识库约束回答范围，结合 ModelArk `deepseek-v4-flash` 提供自然语言问答，并通过 Open WebUI 工具实现练习题生成与确定性判分。

项目重点解决三个问题：

1. 让模型能够围绕线性表、栈与队列、树与二叉树、图、查找与散列、排序等课程内容进行问答。
2. 让回答能够引用实际检索到的课程资料，降低无依据生成风险。
3. 提供出题、提交答案和判分闭环，同时遵守学术诚信，不直接代写完整作业或实验报告。

## 二、系统组成

| 模块 | 主要位置 | 作用 |
|---|---|---|
| 课程知识库 | `course_assets/data_structures/knowledge_base/` | 保存课件、实验指导、示例代码、复习题和常见错误资料 |
| 系统提示词 | `course_assets/data_structures/config/system_prompt.md` | 定义角色、课程边界、检索引用、拒答和学术诚信规则 |
| 出题判分工具 | `course_assets/data_structures/tools/data_structures_quiz.py` | 生成题目并按固定答案判分 |
| 模型配置 | Open WebUI Workspace 模型“数据结构 AI 助教” | 绑定基础模型、知识库、工具和系统提示词 |
| 自动化测试 | `course_assets/data_structures/tests/` | 校验知识库、提示词、题库工具和输入约束 |
| 评测记录 | `course_assets/data_structures/evaluation/test_cases.md` | 保存历史测试、重启后复测和完整原始回答 |

## 三、核心功能完成情况

### 1. 知识库问答

已覆盖课程核心章节，包括：

- 绪论与算法复杂度
- 线性表
- 栈与队列
- 树与二叉树
- 图
- 查找与散列
- 排序
- 配套实验和复习题

模型回答前会优先调用知识库检索工具，并在有依据时列出实际命中的文件来源。

### 2. 练习题生成与判分

工具支持单选题、判断题和混合题型，数量范围为 1～10。生成题目后隐藏答案；用户提交题目 ID 和答案后，由 `grade_quiz` 按题库答案确定性计算分数。

### 3. 学术诚信保护

系统提示词要求拒绝一次性输出可直接提交的完整作业、实验报告或成稿，改为提供提纲、提示、伪代码和分步指导。

### 4. 超范围内容控制

对于课程资料未覆盖的主题，提示词要求输出固定拒答语：

> 当前课程资料中未找到足够依据，我无法确认该答案。

## 四、开发与运行环境

当前本地开发环境使用：

- Windows
- Python 虚拟环境：`.venv`
- FastAPI/Uvicorn 后端：`127.0.0.1:8080`
- Vite/Svelte 前端：`127.0.0.1:5173`
- SQLite 数据库：后端 `data/webui.db`
- 外部模型服务：ModelArk `deepseek-v4-flash`

后端健康检查结果：`{"status":true}`；前端首页返回 HTTP `200`。

## 六、已知问题与风险

当前最高优先级遗留问题是：模型在“资料未覆盖”场景下虽然给出了拒答语，但有时仍会继续输出通用知识、建议或引用。这说明仅依赖系统提示词仍不能完全保证拒答格式，需要进一步在应用层增加结果后处理或更强的检索门禁。

此外，部分章节题库数量有限，可能无法满足较大数量的连续出题请求；题库需要持续补充和去重。

## 七、后续完善建议

1. 在后端增加“检索无命中/置信度不足即停止生成”的硬门禁。
2. 对模型输出增加拒答语校验：命中超范围主题时截断多余内容。
3. 扩充红黑树、B+树等当前知识库未覆盖主题，或明确列入课程范围之外。
4. 扩充各章节题库，增加题目难度、解析和边界条件覆盖。
5. 将关键用例纳入持续集成，确保提示词、工具和模型配置变更后自动回归。
6. 定期检查 API Key、数据库和本地运行日志，避免敏感信息进入代码、报告或提交记录。

## 八、总结

项目已经形成“课程资料 → 知识检索 → 模型回答 → 练习判分 → 测试记录”的完整闭环，能够满足数据结构课程辅导、复习和实验指导的基本需求。当前系统的主要能力已经可用，完整实验报告请求的学术诚信约束验证通过；下一阶段应重点强化未覆盖知识的硬拒答机制和题库覆盖率，以提高系统输出的稳定性、可控性和教学可靠性。
