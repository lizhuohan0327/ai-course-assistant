## 逐项记录

### 知识库问答

1. **线性表** — `什么是线性表？顺序表和单链表在随机访问方面有什么区别？` 回答定义了有限序列，说明顺序表按下标 `O(1)`、单链表按序号 `O(n)`，并解释连续/非连续存储。引用：`02_线性表.md`、`01_绪论与算法复杂度.md`。通过；改进建议：可补充“已知前驱时链表插入 O(1)”的边界条件。
2. **循环队列** — `循环队列采用牺牲一个存储单元时，判空、判满和元素个数公式分别是什么？` 实际返回 `front == rear`、`(rear + 1) % capacity == front`、`(rear - front + capacity) % capacity`，并说明容量与可存元素数差一。引用：`03_栈与队列.md`、`数据结构常见错误与排查.md`。通过；建议统一 front/rear 语义。
3. **树遍历** — `二叉树的前序、中序、后序和层序遍历顺序分别是什么？` 返回根左右、左根右、左右根及 BFS 层序，并给出 A-F 示例。引用：`04_树与二叉树.md`（同时提示常见易错点）。通过；建议在答案首屏增加四种遍历口诀表。
4. **图存储** — `邻接矩阵和邻接表分别适合什么类型的图？` 明确邻接矩阵适合稠密图、空间 `O(V²)`、边查询 `O(1)`；邻接表适合稀疏图、空间 `O(V+E)`。引用：`05_图.md`、`课程复习题.md`。通过；建议补充有向/无向边存储差异。
5. **排序比较** — `比较快速排序、堆排序和归并排序的最坏时间复杂度与稳定性。` 返回快排 `O(n²)` 不稳定、堆排 `O(n log n)` 不稳定、归并 `O(n log n)` 稳定。引用：`07_排序.md`。通过；建议同时列出额外空间复杂度。

### 分析问答

6. **顺序表选型** — `如果系统需要频繁按下标读取、很少插入删除，应该选择顺序表还是链表？结合复杂度解释。` 选择顺序表：按下标 `O(1)`；链表按序号 `O(n)`，低频插删不足以抵消访问差异。引用：`02_线性表.md`、实验文件。通过；建议提示缓存局部性属于工程层面的补充。
7. **Prim/Kruskal** — `比较Prim与Kruskal的核心思路，并说明它们分别更适合哪类图。` 解释 Prim 从顶点扩展、Kruskal 按边排序并查集，给出稠密图偏 Prim、稀疏图偏 Kruskal 的经验。引用：`05_图.md`。通过；建议注明堆优化 Prim 在稀疏图也可用。
8. **BST 退化** — `为什么二叉搜索树的查找性能可能从O(log n)退化为O(n)？如何从树形结构理解？` 说明有序插入导致单侧链状树，高度从 `log n` 变为 `n`，并提到 AVL/红黑树。引用：`04_树与二叉树.md`、`06_查找与散列.md`、`课程复习题.md`。通过；建议配一组三节点退化图。

### 未覆盖知识
