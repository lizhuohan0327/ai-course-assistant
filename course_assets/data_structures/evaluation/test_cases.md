### 知识库问答

1. **线性表** — `什么是线性表？顺序表和单链表在随机访问方面有什么区别？` 回答定义了有限序列，说明顺序表按下标 `O(1)`、单链表按序号 `O(n)`，并解释连续/非连续存储。引用：`02_线性表.md`、`01_绪论与算法复杂度.md`。通过；改进建议：可补充“已知前驱时链表插入 O(1)”的边界条件。
2. **循环队列** — `循环队列采用牺牲一个存储单元时，判空、判满和元素个数公式分别是什么？` 实际返回 `front == rear`、`(rear + 1) % capacity == front`、`(rear - front + capacity) % capacity`，并说明容量与可存元素数差一。引用：`03_栈与队列.md`、`数据结构常见错误与排查.md`。通过；建议统一 front/rear 语义。
3. **树遍历** — `二叉树的前序、中序、后序和层序遍历顺序分别是什么？` 返回根左右、左根右、左右根及 BFS 层序，并给出 A-F 示例。引用：`04_树与二叉树.md`（同时提示常见易错点）。通过；建议在答案首屏增加四种遍历口诀表。

5. **排序比较** — `比较快速排序、堆排序和归并排序的最坏时间复杂度与稳定性。` 返回快排 `O(n²)` 不稳定、堆排 `O(n log n)` 不稳定、归并 `O(n log n)` 稳定。引用：`07_排序.md`。通过；建议同时列出额外空间复杂度。

## 实验一：线性表基本操作 — 指导与提纲

### 一、实验目标（可直接用自己的话复述）

1. 掌握顺序表和单链表的基本实现
2. 理解插入、删除、查找操作
3. 比较顺序存储与链式存储的特点

### 二、数据结构定义

**建议使用课程资料中的结构体**：

```cpp
struct Student {
    int id;
    string name;
    double score;
};
```

### 三、核心伪代码与分步指导

#### 1. 顺序表实现

你可以定义如下类/结构：

```cpp
class SeqList {
    Student* data;      // 动态数组
    int capacity;       // 当前容量
    int size;           // 当前元素个数
};
```

**关键操作伪代码：**

| 操作 | 思路 | 时间复杂度 |
|------|------|:----------:|
| 添加学生 | 检查容量 → 在尾部插入 → size++ | O(1)~O(n) |
| 按学号删除 | 遍历查找 → 移动后续元素覆盖 → size-- | O(n) |
| 按学号查找 | 遍历顺序表，匹配 id 后返回 | O(n) |
| 输出全部 | 遍历 0 到 size-1 依次输出 | O(n) |
| 统计平均 | 遍历累加 score → 除以 size | O(n) |

> **注意**：删除时移动元素要防止越界；插入时若容量不足需扩容（重新申请更大空间并复制数据）。

#### 2. 单链表实现

链表节点定义：

```cpp
struct ListNode {
    Student stu;
    ListNode* next;
};
```

**关键操作伪代码：**

| 操作 | 思路 | 时间复杂度 |
|------|------|:----------:|
| 添加学生 | 尾插法：找到尾节点 → 新建节点链接 | O(n)，有尾指针则 O(1) |
| 按学号删除 | 遍历找到前驱节点 → 修改指针 → delete | O(n) |
| 按学号查找 | 遍历链表，匹配 id | O(n) |
| 输出全部 | 从 head 开始遍历 | O(n) |
| 统计平均 | 遍历累加 → 除节点数 | O(n) |

> **注意**：删除节点时一定要保存前驱节点；删除后记得 `delete` 释放内存，避免内存泄漏。

### 四、测试数据建议（按实验要求）

| 测试用例 | 说明 |
|----------|------|
| 空表插入 | 表为空时添加第一个学生 |
| 表头插入 | 插入到第一个位置 |
| 表尾插入 | 追加到末尾 |
| 删除不存在元素 | 返回错误提示，不崩溃 |
| 删除首节点 | 注意头指针更新 |
| 删除尾节点 | 注意前驱的 next 置空 |
| 连续删除多个 | 验证删除后遍历正确 |

### 五、复杂度分析（验收重点）

**顺序表 vs 单链表对比表【来源：02_线性表.md】:**

| 操作 | 顺序表 | 单链表 |
|------|:------:|:------:|
| 按下标访问 | **O(1)** | O(n) |
| 查找指定值 | O(n) | O(n) |
| 表尾插入 | O(1)~O(n) | O(n)，有尾指针时 O(1) |
| 已知位置插入 | O(n)（需移动元素） | 找到前驱后 **O(1)** |
| 删除 | O(n)（需移动元素） | 找到前驱后 **O(1)** |

### 六、思考题提示

1. **频繁按下标读取** → 优先选**顺序表**（O(1) 随机访问）
2. **频繁在中间插入删除** → 链表不一定更快，因为**找到插入位置本身就需 O(n) 遍历**【来源：02_线性表.md】
3. 链表插入虽然后续操作是 O(1)，但定位到目标位置的前驱仍需 O(n)，整体仍是 O(n)
